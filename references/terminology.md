# 术语抽取与锁定规则（terminology）

## 目标

让同一术语在标题、摘要、正文、图注、结论中始终使用同一译名，并把术语表做成**真实可执行的文件**，而不是写在提示词里的口号。

## 抽取范围（按优先级）

1. 标题、摘要、关键词
2. 各级节标题
3. 正文首现处（首次出现的专业术语优先录入）
4. 图注、表题、表头
5. 结论与讨论中反复出现的核心概念

## 术语表字段（每条一行/一个对象）

模板见 `../assets/glossary-template.md`，字段固定为：

| 字段 | 说明 |
|-|-|
| `term` | 源词（规范形式，小写单数，除非专有名词） |
| `translation` | 锁定译名（唯一） |
| `variants` | 变体：复数、连字符、大小写、缩写、全称、同义/近义 |
| `first_seen` | 首现定位（页码/段号/图注位置） |
| `note` | 判定依据、学科惯例、歧义说明 |

## 锁定规则

1. **一词一译**：同一 `term` 全篇只用 `translation`；变体映射回同一译名。
2. **缩写**：首次出现写 `全称（缩写）`，之后只出现锁定缩写；缩写与全称必须互相指认。
3. **保留原文的类别**：人名、机构名、地名、化学式、变量符号、软件/模型/数据集专名、基因/蛋白质名（按学科惯例）。这些不译，但在术语表中登记，避免被误译。
4. **多义词**：按上下文锁定一个译名，`note` 写明"此处取 X 义，因……"；不同义项若必须区分，新增两条并注明区分条件。
5. **复合术语**：优先按领域习惯整体翻译；无法整体译时保持组成部分译名一致。
6. **单位与符号**：SI 单位、量符号、缩写符号一律保留，术语表中只登记"是否翻译"的约定，不改动。
7. **冲突处理**：同一源词在不同语境确实需要不同译名时，必须显式列出并标注语境；不得静默混用。

## 执行方式（关键）

- 术语表文件（`/app/work/glossary.md`）一旦建立，翻译阶段**逐段对照**该文件。
- 每译一段，检查该段出现的术语是否都已收录：未收录的补录并锁译名，再继续翻译。
- 翻译结束后做"全篇回填"：扫描译文，确认每个术语只出现锁定译名；发现未统一处回改并记录进 `change_records`。

## 术语表最小示例

```text
| term | translation | variants | first_seen | note |
|-|-|-|-|-|
| Bayesian inference | 贝叶斯推断 | bayesian inference | §2 P4 | 通译 |
| Markov chain Monte Carlo | 马尔可夫链蒙特卡洛 | MCMC | §2 P5 | 首次写全称（MCMC） |
| posterior distribution | 后验分布 | posterior | §2 P4 | 锁定"后验分布" |
| PyTorch | PyTorch | - | §3 P1 | 软件名，保留原文 |
```
