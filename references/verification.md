# 译文自检规则（verification）

翻译完成后逐项检查，产出 `/app/work/verification.md`。每一项给出：通过/未通过、定位（页码/段号/原文短语）、处理动作。未通过且无法当场解决的，进入"需人工确认清单"。

确定性检查可调用配套脚本（环境提供 Python 时）：

```bash
python3 scripts/check_consistency.py --glossary glossary.md --bilingual bilingual.md --json check.json
```

脚本做两项机械检查：术语源词/变体是否泄漏进译文（疑似未译/译名不一致）、段落单元号是否连续无重号。脚本只报机械问题，不能替代下面的语义核验。

## 1. 术语一致性

- 抽取标题、摘要、正文、图注、结论中出现的目标术语；
- 逐项比对是否等于 `glossary.md` 的锁定译名；
- 发现同源词出现不同译名 → 回改统一，并在 `change_records` 记录；
- 检查变体（复数/缩写/连字符）是否被正确映射，没有漏掉同义不同形。

## 2. 段落完整性

- 译文单元 `unit_id` 集合与 `source-paragraphs.md` 一一对应；
- 无漏段（原文有译文无）、重段（同一段出现两次）、错位（段号对应错原文）；
- 跨页/跨栏段落只出现一次，且原文定位标注正确。

## 3. 数字与单位

- 数值、数量级、上下标、范围（`3–5`、`[0,1]`）、百分比、指数与原文一致；
- 单位符号（`nm`、`m/s`、`kJ/mol`、`°C`）原样保留，不译不换；
- 大小写敏感的符号（`k` 与 `K`、`M` 与 `m`）保持。

## 4. 公式与编号

- 公式 LaTeX 原样保留，不"意译"、不改符号；
- 公式编号（`(1)`、`(12)`、`Eq. 3`）、图/表编号（`Fig. 2`、`Table 1`）保留并与原文一致；
- 正文对公式/图/表的引用（"见式(2)"、"如图 3 所示"）指向的编号一致。

## 5. 文献引用

- 引用标记（`[12]`、`(Smith et al., 2020)`、上标数字）与原文一一对应，不重编号、不增删；
- 参考文献表（若翻译）作者名、年份、DOI、卷期页码保留原文，仅译可读部分。

## 6. 关系准确

- 否定：not/no/never/without/absence/neither…nor 等译为明确否定，不弱化；
- 限定：only/unless/provided that/if and only if/at most 等限定范围不扩大不缩小；
- 因果：because/therefore/lead to/result in 等方向不颠倒；
- 让步/转折：although/however/despite/whereas 等关系保留；
- 指代：it/this/these/which 等的先行词在译文中可还原，不张冠李戴。

## 7. 需人工确认清单

凡属以下情况，逐条列出（含定位与原因）：

- 原文残缺、模糊、OCR 低置信；
- 公式/表格为图片，无法可靠抄录；
- 术语存在学科争议或多译法，需专家定夺；
- 指代不明、长难句有歧义、否定范围不清晰；
- 语言混杂或异常排版导致边界不确定。

清单格式：

```text
| # | unit_id | page | 原文短语 | 问题 | 建议/待确认 |
|-|-|-|-|-|-|
| 1 | P12 | 5 | "the former" | 指代二选一不明 | 需结合上下文人工确认 |
```

## 输出

把自检结果与清单写入 `verification.md`，并在 `result.json` 的 `uncertainty` 与 `change_records` 中同步关键结论。
